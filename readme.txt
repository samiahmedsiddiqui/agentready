Serves an llms.txt index and a clean Markdown version of every page, so AI agents can read your content.

== Description ==

AgentReady builds a Markdown version of each page from its rendered output, so ACF fields, Gutenberg blocks, Elementor layouts and classic editor content are all included.

* `/llms.txt` and `/llms-full.txt`, generated automatically or customised.
* A `.md` version of every page, for example `/about.md`.
* All public post types enabled by default, with a setting to exclude any of them.
* Hide individual pages from the editor, or exclude by ID, URL pattern or taxonomy term.
* Per-page description override for `llms.txt`.
* A preview tool to test the generated Markdown for any URL.
* Drafts, private and password-protected content are never exposed.
* Optional robots.txt rules that allow AI crawlers.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/agentready`, or install it from the Plugins screen.
2. Activate the plugin.
3. Visit Settings > AgentReady to choose post types and the `llms.txt` mode.
